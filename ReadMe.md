## PyBox 是什么？

PyBox 是一个「应用容器平台」。说人话就是：**一个能让你运行、制作、分享各种小软件的工具箱。**

你可能遇到过这些情况：

- 想用个记流水账、待办清单、抽奖、批量生成二维码的小工具，网上要么要钱、要么装一堆乱七八糟的东西；
- 想自己做个「表白网页」「摸鱼小游戏」「帮同事做表格的脚本」，但一看代码就头疼；
- 用 Word、Excel 干重复的活，想找个人（或者工具）帮你自动做完。

PyBox 就是为这些场景做的。它把最麻烦的部分（装环境、配软件、写代码）全都打包藏起来，你只需要**点一点、说一句话**，剩下的事交给它。

## 它能帮你做什么？

### 👵 对电脑小白：开箱即用，点点鼠标就行

- **不用装 Python，不用配环境**。装好 PyBox，内置的运行环境全都准备好了，下载一个应用，点一下就能跑。
- **商店里逛一逛，看到喜欢的直接拿走**。商店里有很多别人做好的小工具，下载即用，不用管它背后是怎么写的。
- **界面有明亮 / 暗黑两种主题**，看起来舒服，字也大。

### 👔 对办公白领：让 AI 帮你干重复活

- **办公秘书**：把 Word、Excel、PDF 丢给它，用大白话说「帮我把这个表格里的重复项删掉」「把这份 PDF 的文字整理出来」，它就帮你做。
- **批量处理**：批量生成二维码海报、批量改文件名、整理表格数据……那些你每周都在重复点鼠标的活，都可以交给它。
- **一句话生成小工具**：跟它说「帮我做一个每天提醒我喝水的工具」，它直接帮你写好、跑起来。

### 👶 对编程初学者：从「抄代码」到「说需求」

- **用大白话做软件**：在「研发中心」里描述你想要什么，AI 帮你写代码、帮你运行，你可以一边看它怎么做，一边学。
- **做好能打包成 exe**：你做的第一个小工具，可以变成一个双击就能用的文件，发给朋友、家人用，特别有成就感。
- **不用从头配环境**：环境 PyBox 已经帮你装好了，你可以把精力放在「想做的东西」上，而不是「怎么装这装那」上。

## 怎么开始？

1. 打开官网 👉 **[https://pybox.site](https://pybox.site)**
2. 点导航栏的「下载」，下载安装包并安装
3. 打开 PyBox，注册一个账号（会送专属积分）
4. 去「应用商店」逛一圈，或者直接去「研发中心」说一句话，让 AI 帮你做第一个小软件

> 💡 新手第一次打开会有引导教程，跟着走一遍就熟悉了。
